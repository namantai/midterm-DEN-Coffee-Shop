# DEN Coffee Shop — Midterm Project

## Project idea
DEN Coffee Shop is a responsive multi-page coffee shop website. The design follows the provided black, white and gray coffee-shop mockup with a large logo, simple navigation, coffee images and minimal content.

## Pages
1. `index.html` — Home page
2. `menu.html` — Coffee menu, Bootstrap carousel and price table
3. `about.html` — Information about the coffee shop
4. `gallery.html` — 6-image CSS Grid gallery
5. `contact.html` — Contact information and contact form

## Technologies
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Bootstrap 5.3.6 (local CSS and JS files)
- Two responsive CSS breakpoints: 992px and 576px

## Requirements included
- 5 connected pages with the same navigation bar
- Semantic tags: `header`, `nav`, `main`, `section`, `figure`, `footer`
- Headings, paragraphs, links, images and lists/structured content
- Table on the Menu page
- Form on the Contact page
- Flexbox in navigation, Home and About sections
- CSS Grid in the Gallery
- Positioning for the Menu background strip and About decorative elements
- Bootstrap grid (`container`, `row`, `col-md-*`)
- Bootstrap utilities (`text-center`, `mb-*`, `g-*`, buttons and table classes)
- Responsive media queries for tablet and mobile

## How to open
Open `index.html` in a browser.
